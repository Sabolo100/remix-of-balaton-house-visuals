# Remix of Balaton House Visuals

Készíts egy web oldalt, melyen könnyen, gyorsan egyszerűen meg lehet nézni az alábbi 15-20 csatolt jpg képfilet – nem is kell más info igazán

3-t csatolok példának – mivel nagyok, többit utána töltöm fel

A filek egy balatoni  társasház épületének, mely A és B lépcsőháznól áll, szint alaprajzait tartalmazza, valamint különböző irányokból metszeti, oldalnézeti rajzot

-           A képek caroussel szerűen jelenjenek meg nagy kép felül, alul kis thuimbnailek

-          Mobiloptimalizáció fontos

-          Rákattintva megjelennek tlejes méretben és letötlhetők

 

A web oldalnak azt kell kiváltania, hogy egy balatoni társasház fejelsztési projekt érdeklődi nem tudják ezeket megnézni a projekt web oldalán, mivel oda nem akarja kitenni a fejelztő, de az érdeklődőknek egy egyszerű linkkel el akarják küldeni

 

Itt van egyébkétn a társasház projetk web oldala, designban ehhez hasonlítson

Az meglévő oldal, arany-barna színét használd
